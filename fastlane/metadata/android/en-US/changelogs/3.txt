First public release.

Phonon packages llama.cpp as a foreground service, downloads a GGUF model into
app storage (HTTP range resume, size verified), supervises the server, and
serves an OpenAI-compatible API (chat completions and tool calls) on the phone's
loopback interface by default. Adds thermal pause/resume, a bounded log ring,
device benchmarking and a one-button device report. Optional Device-Owner
appliance mode for unattended operation.
